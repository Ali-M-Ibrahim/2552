1) To create Laravel project:
composer create-project Laravel/Laravel appName


2) To run Laravel project:
go to your project folder, open terminal and run:
php artisan serve


3) Upon cloning the project from GitHub always 
  - copy .env.example and name it .env
  - execute: composer install
 to create vendor folder


4) To check list of available routes
php artisan route:list


5) to create a plain controller, we use:

php artisan make:controller controllerName

the controller will be created under app/http/controllers
